# راهنمای نسخهٔ پژوهش تاریخی ۰٫۲

این نسخه فایل دادهٔ تاریخی را می‌خواند، کیفیت آن را بررسی می‌کند و شاخص‌های SMA20، SMA50، RSI14 و ATR14 را محاسبه می‌کند. گزارش را می‌توان به Markdown یا JSON ذخیره کرد. نمونهٔ همراه کاملاً ساختگی است و قیمت واقعی طلا یا دارایی دیگری نیست.

## شروع سریع در Codespaces

۱. محیط پروژه را باز کن و از Terminal → New Terminal وارد ترمینال شو.
۲. در پوشهٔ اصلی مخزن این دستورها را اجرا کن:

~~~bash
python -m pip install -e ".[dev]"
python -m openmarket_ai --example
python -m pytest
~~~

برای ذخیرهٔ گزارش نمونه، یک نام جدید انتخاب کن:

~~~bash
python -m openmarket_ai --example --output sample-report.md
python -m openmarket_ai --example --format json --output sample-report.json
~~~

اگر فایل خروجی قبلاً وجود داشته باشد، برنامه آن را بازنویسی نمی‌کند. برای گزارش بعدی نام تازه‌ای انتخاب کن. گزارش باید SYNTHETIC_RESEARCH و ABSTAIN داشته باشد. این اجرای نمونه به اینترنت یا کلید API نیاز ندارد؛ نصب اولیه به اینترنت نیاز دارد.

## اجرای فایل خودت

فایل باید UTF-8 و شامل دست‌کم ۵۰ کندل بسته‌شده باشد. سطر عنوان دقیقاً به این شکل است؛ ستون volume اختیاری است:

~~~csv
timestamp,open,high,low,close,volume
2020-01-01T00:00:00Z,100,102,99,101,1000
~~~

این سطر صرفاً نمونهٔ ساختگی قالب است. زمان‌ها باید ISO 8601 با منطقهٔ زمانی، یکتا و از قدیم به جدید باشند. زمان‌ها در گزارش به UTC تبدیل می‌شوند. قیمت‌ها باید مثبت، متناهی و سازگار باشند؛ حجم باید غیرمنفی باشد. محدودهٔ عددی پشتیبانی‌شده تا ۱ تریلیون، اندازهٔ فایل تا ۲۰ MiB و تعداد ردیف تا ۱۰۰ هزار است. دادهٔ خالی، خراب یا آینده رد می‌شود. شکاف‌های زمانی گزارش می‌شوند و پر نمی‌شوند. تعطیلی بازار نیز ممکن است شکاف ایجاد کند.

فایل را فقط با مجوز استفادهٔ مناسب وارد کن. این ابزار مجوز یا اصالت منبع را تأیید نمی‌کند. دادهٔ خصوصی را در مخزن عمومی بارگذاری نکن.

مثال زیر با نام‌های فرضی است؛ مشخصات منبع، مجوز، بازار و قرارداد را با مشخصات واقعی فایل خودت جایگزین کن. گزینهٔ closed-bars یعنی تأیید می‌کنی همهٔ کندل‌ها بسته شده‌اند:

~~~bash
python -m openmarket_ai --csv history.csv --symbol XAUUSD --source "Your permitted data source" --data-license "Your permitted usage terms" --venue "Your data venue" --instrument-type "Your instrument type" --quote-currency USD --timeframe 1h --closed-bars --output history-report.md
~~~

تایم‌فریم‌های پشتیبانی‌شده: 1m، 5m، 15m، 30m، 1h، 4h، 1d و 7d. فاصلهٔ ردیف‌ها باید برابر تایم‌فریم یا مضرب صحیح آن باشد. ابزار تقویم بازار یا تغییر ساعت تابستانی را مدل نمی‌کند؛ دادهٔ نامنطبق باید ابتدا با روش مستند استاندارد شود. واحد حجم را منبع تعیین می‌کند؛ از آن سیگنالی محاسبه نمی‌شود.

## چه چیزی در گزارش هست؟

- نام نماد، منبع، مجوز اعلام‌شده، محل بازار، نوع ابزار و ارز مظنه
- تعداد کندل‌ها، شروع و پایان داده به UTC، آخرین قیمت بسته‌شدن و تعداد فاصله‌های نامنظم
- اثرانگشت SHA-256 فایل و نسخهٔ نرم‌افزار برای بازتولید پژوهش
- محاسبات شاخص‌ها، وضعیت هم‌راستایی میانگین‌ها و فرضیه‌های شرطی
- محدودیت‌های داده و روش، همراه با ABSTAIN؛ سفارش یا پیشنهاد شخصی تولید نمی‌شود

دادهٔ CSV همواره تاریخی و تأییدنشده از نظر تازگی نمایش داده می‌شود. حتی اگر آخرین زمان داده جدید باشد، ابزار آن را قیمت زنده نمی‌نامد.

## اجرا روی ویندوز

Python نسخهٔ ۳٫۱۰ یا بالاتر لازم است. پس از دریافت مخزن، در پوشهٔ پروژه:

~~~powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m openmarket_ai --example
.venv\Scripts\python.exe -m pytest
~~~

نیازی به تغییر سیاست امنیتی PowerShell نیست. در لینوکس یا macOS، می‌توانی از .venv/bin/python به‌جای مسیر ویندوز استفاده کنی.

## وضعیت تکمیل

نسخهٔ اولیهٔ پژوهش آفلاین آمادهٔ استفاده است: ورود CSV، اعتبارسنجی، شاخص‌ها، گزارش، خروجی فایل و آزمون خودکار. دریافت دادهٔ زنده، اخبار، تحلیل بنیادی، مدل‌های هوش مصنوعی، بک‌تست، سیگنال معتبر و سکوی عمومی هنوز در نقشهٔ راه هستند. این امکانات به منبع مجاز و طراحی و ارزیابی جداگانه نیاز دارند؛ نام پروژه به معنی وجود مدل AI در نسخهٔ فعلی نیست.
